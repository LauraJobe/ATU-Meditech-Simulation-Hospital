Wristbands & Medication Labels

Print at 100% / "Actual size" (not "Fit to page") so the labels come out at their real size: medication labels 40 × 19 mm (about 1.6 × 0.75 in), unit-dose labels 35 × 16 mm, wristbands 25 mm tall. ATU barcodes (default) reprint the accepted, already-installed labels: Code 39 wristband codes 1000–1012 and Code 128 MED-#### package labels. QR squares scan with the iPad/tablet camera (hold 3–6 inches away) and with any 2D hand scanner (USB or Bluetooth). Data Matrix is the square code printed on real unit-dose blister packs and vials; it scans with 2D hand scanners, but the iPad camera often misses it next to label text, so use it only with hand scanners. Choose Linear (1D) only if your hand scanner reads lines but not squares. Wristbands always carry a linear code and a square code. The number on each label can also be typed into the scan box. Labels include medications from scenario events and orders entered during the sim.
